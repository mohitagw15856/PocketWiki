# PocketWiki sample: Foundations of Science

This directory contains 50 short sample articles for building a demonstration PocketWiki archive (a `.pwa` file). The collection is titled *Foundations of Science* and covers well-known public-domain topics: historical scientists, classical scientific concepts, astronomy and natural history.

## About the content

All of the text here is **original prose**, written specially for this sample. It describes widely known, public-domain facts and does not copy from Wikipedia or any other source. The articles are written in British English and are intended to be factual, encyclopaedic and neutral in tone.

Each article is stored as a single Markdown file, named with a lowercase, hyphenated slug (for example, `isaac-newton.md`). Every file begins with a small block of YAML front matter giving the human-readable title, followed by the body text. Articles link to one another using Markdown links whose targets are the slug filenames, so the collection forms a connected web of cross-references suitable for offline browsing.

## Intended use

These files are provided as sample material for testing and demonstrating the PocketWiki reader and the archive build process. They exercise the subset of Markdown that the reader supports: headings, paragraphs, bold and italic text, ordered and unordered lists, horizontal rules and internal links.
